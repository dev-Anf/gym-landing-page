# GRAFIT – Gym Website

A modern, responsive landing page for a fitness club with an online booking form.

🔗 **Live demo:** [https://dev-anf.github.io/gym-landing-page/](https://dev-anf.github.io/gym-landing-page/)

**Status:** in progress

## Features
- Landing page: hero, programs carousel, memberships, contacts
- Fully responsive layout (desktop, tablet, phone)
- Booking form with validation
- Booking requests delivered to Telegram or email (planned)

## Tech stack
- **Frontend:** HTML5, CSS3, vanilla JavaScript
- **UI:** Bootstrap 5 (carousel), Lucide icons, Google Fonts (Bebas Neue, Inter)
- **Notifications:** Telegram Bot API or an email service (EmailJS / Formspree)
- **Hosting:** GitHub Pages
