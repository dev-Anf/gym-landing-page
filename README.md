# GRAFIT – Full-Stack Gym Website

A modern website for a fitness club with online booking and an admin panel for the owner.

**Status:** in progress

## Planned features
- Landing page: programs, memberships, trainers, schedule, contacts
- Online booking for trial sessions and group classes (with seat limits)
- Admin panel: manage bookings, prices, schedule and trainers
- Telegram notifications for new bookings

## Tech stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** ASP.NET Core Web API, C#
- **Database:** SQL Server, Entity Framework Core
- **Auth:** JWT / ASP.NET Identity
- **Hosting:** GitHub Pages (frontend), MonsterASP.NET (API)
